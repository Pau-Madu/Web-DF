## 🚀 Instalación

Para configurar el proyecto en un entorno local, asegúrate de tener Node.js instalado y ejecuta los siguientes comandos en tu terminal:

```bash
# Clona el repositorio (si no lo tienes en local)
git clone <url-de-tu-repositorio>

# Entra en la carpeta del proyecto
cd Web-DF

# Instala todas las dependencias necesarias
npm install
